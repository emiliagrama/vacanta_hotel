# Hotel Vacanța

Production hotel website built for a real client in Romania.

The project was designed and developed from scratch, including custom pages, contact forms, newsletter subscriptions, image galleries, analytics integration, and an admin-managed blog.

## Project Goals

- Present hotel services and offers
- Allow visitors to contact the hotel
- Promote vacation packages
- Improve online visibility through SEO
- Provide a simple content management experience

## Features

- Responsive design
- Custom image galleries
- Fullscreen photo viewer
- Contact form with email notifications
- Newsletter subscriptions
- Blog with admin dashboard
- SEO optimization
- Google Analytics integration
- Cookie consent management
- Mobile-friendly experience

## Tech Stack

### Backend

- Ruby on Rails
- PostgreSQL
- Action Mailer

### Frontend

- JavaScript
- Stimulus
- Bootstrap
- CSS

### Deployment

- Heroku
